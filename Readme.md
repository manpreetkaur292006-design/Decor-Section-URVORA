# 📖 About the Project

The Decor Section showcases modern home décor collections with a clean and responsive user interface. The goal was to create an aesthetically pleasing shopping experience while maintaining performance, responsiveness, and usability.

This project focuses on:

- Elegant UI Design
- Responsive Layout
- Interactive Product Cards
- Smooth Navigation
- Modern Styling

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/manpreetkaur292006-design/Decor-Section-URVORA.git
````

### Navigate to the project

```bash
cd Decor-Section-URVORA
```

### Open the project

Simply open the `index.html` file in your browser or use the Live Server extension in VS Code.
